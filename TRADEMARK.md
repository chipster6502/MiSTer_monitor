# MiSTer Monitor — Name and Branding Policy

The name **"MiSTer Monitor"**, the project logo, and the official
screenshots and demo videos identify this project and its author,
chipster6502. They are unregistered (common-law)
identifiers, and this policy exists for one reason: so that nobody is
misled into paying for something believing it is official, endorsed,
or supported by this project when it is not.

The source-code licenses (GPL-3.0 / AGPL-3.0) cover the *code*. They
do **not** grant any right to use the project's name, logo or official
media as branding.

## You do NOT need permission to

- Refer to the project truthfully: articles, reviews, tutorials,
  videos, forum posts, package descriptions.
- Say that something **"works with"**, **"is compatible with"** or
  **"is based on"** MiSTer Monitor.
- Link to the repository, the web flasher or the official media in
  informational contexts.
- Build the firmware from source and flash it for yourself, your
  friends or your community, at no charge.

## Please ask first (open a GitHub issue) before

- Using the name "MiSTer Monitor" or the logo to **sell** hardware,
  kits, pre-flashed displays, or services of any kind.
- Using the official screenshots or demo videos in commercial
  listings.
- Registering domain names, store pages or social-media handles that
  could be understood as official.

## Not allowed

- Marketing pre-flashed devices as "MiSTer Monitor" in a way that
  implies they are official products or that this project endorses or
  supports them.
- Using a confusingly similar name for a modified fork that is
  distributed publicly. Forks are welcome under the GPL/AGPL — please
  give yours a different name; stating "based on MiSTer Monitor" is
  perfectly fine and appreciated.

## Commercial use in exchange for contributions

Permission to use the project name and logo commercially can be
granted — it is not reserved for the author alone. The intent of this
policy is not to keep others out, but to make sure that anyone
profiting from the project is also helping it grow.

A commercial branding agreement may be granted in exchange for
significant, sustained contributions back to the official project.
That can take several forms:

- Code: new board ports, features, or maintenance of existing ones.
- Hardware: enclosure or PCB designs released openly, or test units
  for boards the project does not yet support.
- Infrastructure: documentation, translations, user support.
- Financial support that funds the project's development.

Agreements are informal, case by case, revocable if the terms stop
being met, and never exclusive: granting one does not prevent others
from receiving the same. To propose one, open an issue describing
what you would like to sell and what you intend to contribute.

Note that a commercial build must in any case be compiled from source
with your own ScreenScraper developer credentials — the official
pre-built binaries may not be redistributed commercially (see
`LICENSE`).

## About "MiSTer"

This project is an unofficial companion for the
[MiSTer FPGA](https://github.com/MiSTer-devel) platform. No rights
are claimed over the name "MiSTer" itself, which identifies the
MiSTer FPGA project and its community.
